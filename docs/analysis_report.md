## 3. Does late delivery hurt satisfaction?

- On-time deliveries: **4.28** average review (n = 89,936)
- Late deliveries: **2.26** average review (n = 6,534)
- Difference: **2.02 stars** (95% CI 1.99 to 2.06)
- Mann-Whitney U test: p = 0.000e+00
- Cliff's delta (effect size): 0.64
- 1-star reviews: 54.2% of late orders vs 6.8% of on-time orders

**Reading it:** the p-value only says the difference is unlikely to be chance, which is easy to achieve with tens of thousands of rows. The effect size and the gap in 1-star reviews are what make this worth acting on.

**Caveat to state out loud:** this is observational data, so it shows association, not proof of cause. Orders that run late may differ in other ways too (distance, product type, seller).
