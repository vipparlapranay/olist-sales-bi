# Screenshots

Captures of the web dashboard (`docs/index.html`), one per view, rendered at 1440px wide
at 2x for legibility. They are generated from the page itself, so they stay honest: if
the dashboard changes, re-render rather than editing an image.

| File | View |
|---|---|
| `01_sales.png` | Revenue trend, region split, ABC concentration, order profile |
| `02_products.png` | Top categories by ABC class, revenue against satisfaction |
| `03_delivery.png` | The review gap, as rates, with the significance test |
| `04_customers.png` | RFM segments by headcount and value |
| `05_risk.png` | Model against baseline, feature weights, confusion matrix |

The Power BI `.pbix` is excluded from the repository for size. Add page captures here as
`powerbi_01_*.png` and reference them from the main README if you want both front ends
shown.
